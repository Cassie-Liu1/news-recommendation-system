# Source and publication scope

The published snapshot contains executable Python pipelines, tests, measured
experiment reports and dependency specifications from the current project.

Original owner-supplied notebooks and their extracted EDA images are retained
locally but excluded pending authorship and publication-permission confirmation.
Raw click logs, article metadata, embeddings and trained models are not distributed.

Dataset reference: https://tianchi.aliyun.com/competition/entrance/531842
The filenames match the Tianchi news-recommendation task. This reference is not
a verification of the lineage or license of the owner's exact local copies.
Users must obtain data separately under its applicable terms.

New measured experiments are described in temporal-study.md and rolling-study.md.
Historical narrative metrics are not evidence for the new implementation.
No blanket license is granted over third-party data or teaching materials.
